
# 🌍 NGO Website

A modern, responsive website built for an NGO to spread awareness, showcase initiatives, and connect with supporters.

## 🚀 Project Overview

This project is a static website designed to represent an NGO’s mission and activities online. It includes an **About section**, **Programs page**, **Gallery**, and a **Contact form** powered by Formspree for easy communication.

## 🛠️ Built With

* **HTML5** – for the website’s structure
* **CSS3** – for layout and styling
* **JavaScript** – for interactivity and smooth user experience
* **Formspree** – to handle contact form submissions without a backend

## ✨ Features

* Responsive and user-friendly design
* Interactive navigation and smooth scrolling
* Contact form with Formspree integration
* Optimized for accessibility and performance

## 📬 Contact Form Setup

1. Create a Formspree account and get your unique form endpoint.
2. Replace the existing Formspree URL in the contact form’s `action` attribute with yours:

   ```html
   <form action="https://formspree.io/f/your-form-id" method="POST">
   ```
3. That’s it! Messages will be sent directly to your email.
